# Бот «Вырасти Артёма»

Телеграм-бот для чатов: каждый игрок раз в день растит своего Артёма, а бот ведёт рейтинг внутри чата. Игроки могут вызывать друг друга на дуэли в мини-играх и ставить сантиметры.

## Команды
- `/artem` - вырастить Артёма (раз в день; может вырасти или уменьшиться)
- `/stats` - статистика игроков чата (размер, число игр, победы/поражения в дуэлях)
- `/duel` - дуэль с другим игроком (см. ниже)
- `/help` - справка

## Дуэли
Ответь командой `/duel` на сообщение соперника:

- `/duel` - случайная игра, ставка 1 см
- `/duel кубик 5` - выбранная игра и ставка 5 см (порядок слов неважен)

Соперник получает сообщение с кнопками «Принять» / «Отказаться» (120 секунд на ответ). Проигравший отдаёт ставку победителю. Артём не может стать меньше 1 см, поэтому ставка ограничена размерами обоих игроков и максимумом `MAX_BET` (20 см).

| Игра | Команда | Как определяется победитель |
|------|---------|-----------------------------|
| 🎲 Кубики | `кубик` | у кого выпало больше |
| 🎯 Дартс | `дартс` | у кого больше очков (6 - в яблочко) |
| 🎳 Боулинг | `боулинг` | у кого больше кеглей (6 - страйк) |
| 🏀 Баскетбол | `баскетбол` | попал тот, кто забил, а соперник нет |
| ⚽ Футбол | `футбол` | забил гол тот, кто попал, а соперник нет |
| 🎰 Слоты | `слоты` | комбинация лучше: 7️⃣7️⃣7️⃣ > тройка > пара > ничего |
| ✊ КНБ | `кнб` | камень-ножницы-бумага, выбор скрыт кнопками |

Случайная игра: `/duel` без названия или `/duel рандом`. При ничьей бросок переигрывается до 3 раз, потом засчитывается ничья (размеры не меняются). В КНБ тот, кто не выбрал за 60 секунд, проигрывает.

Игрок, который ещё ни разу не играл в этом чате, автоматически получает стартовые 10 см.

## Запуск
1. Создай бота у @BotFather и получи токен.
2. Скопируй `.env.example` в `.env` и впиши токен: `BOT_TOKEN=123456:ABC...`
   (переменная окружения `BOT_TOKEN` тоже работает и имеет приоритет над `.env`).
3. Запусти `python bot.py`. Нужные библиотеки (aiogram, tzdata) скачаются сами при первом запуске.
4. Добавь бота в группу. Если он не видит команды - в @BotFather: `/setprivacy` -> Disable (или сделай бота админом).
5. Список команд в меню: у @BotFather `/setcommands`:
   ```
   artem - Вырастить Артёма
   stats - Статистика чата
   duel - Дуэль (ответом на сообщение соперника)
   help - Справка
   ```

## Картинки
Создай папку `images` рядом с `bot.py` и положи файлы (jpg, png, webp, gif) в подпапки.
Из каждой папки бот берёт случайную картинку:

| Папка             | Когда показывается                          |
|-------------------|---------------------------------------------|
| `images/grow`     | Артём вырос                                 |
| `images/shrink`   | Артём уменьшился                            |
| `images/same`     | размер не изменился                         |
| `images/stats`    | команда `/stats`                            |
| `images/wait`     | игрок уже играл сегодня                     |
| `images/duel`     | началась дуэль                              |
| `images/duel_win` | в дуэли определился победитель              |

Если папка пустая или её нет, бот отправит просто текст.

## Настройки
В начале `bot.py`: стартовый размер, шанс роста, диапазоны роста/уменьшения, минимальный размер, размер топа, а для дуэлей - ставка по умолчанию, максимальная ставка, таймауты, число переигровок.
Часовой пояс сброса дня: переменная `TZ_NAME` (по умолчанию `Europe/Kaliningrad`).
Данные хранятся в `artem.db` (SQLite). Старая база от прошлой версии подхватится сама: колонки для дуэлей добавятся автоматически.
